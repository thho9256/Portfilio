Wolfenstein Assault 2049 - RTOS Architecture

The Wolfenstein Assault 2049 project demonstrates my expertise in embedded systems and real-time operating systems. Below is the task architecture I designed and implemented:

  • gyroTask: Reads gyroscope data via SPI at 50Hz, processes tilt information, and updates tank direction with mutex protection
  • physicsTask: Runs physics calculations at 100Hz, applying gravity, updating object positions, and checking for collisions
  • LCDTask: Handles screen rendering at 30Hz, drawing all game elements based on the current game state
  • buttonTask: Processes user input with debouncing, manages shot charging mechanics, and implements double-tap shield activation
  • energyTask: Controls energy regeneration and depletion, providing game balance
  • LEDTask: Updates LED indicators based on game state (charging, shield active, low energy)

The system uses mutexes for shared resources, semaphores for synchronization, and message queues for inter-task communication. This design ensures real-time responsiveness while maintaining clean separation of concerns.
